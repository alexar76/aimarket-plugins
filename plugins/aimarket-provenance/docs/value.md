# aimarket-provenance — Value

## English

Every AI answer gets a cryptographic receipt — which model, when, over which input and
output digests, signed by whom — verifiable years later, offline, by anyone, with no registry
and no call back to the hub that issued it. An AWR/2 Verifiable Credential: like a fiscal
receipt for AI output, except the whole receipt is signed, so it cannot be renamed or
re-pointed after the fact.

## Русский

Каждый ответ AI получает криптографический чек — какая модель, когда, по каким хешам ввода и
вывода, кем подписан — проверяемый спустя годы, офлайн, кем угодно, без реестра и без
обращения к хабу-эмитенту. Verifiable Credential формата AWR/2: как фискальный чек для
результата AI, только подписан весь документ целиком — переименовать его или переподвесить
цепочку задним числом нельзя.

*Format: [AWR/2](../../../../awr/SPEC.md) · `eddsa-jcs-2022` over RFC 8785 · `did:key`*
